# ✝️ البوت القبطي التعليمي (خادم) — Coptic Learning Hub v3

منصة قبطية تعليمية تفاعلية للخدام والشباب، مبنية كموقع ثابت (HTML/CSS/JS بدون أي backend).
طُوّرت من مشروع «خادم AI» **بدون حذف أي ميزة كانت تعمل**، مع تحوّل جوهري:

> **لا مفتاح Gemini، ولا أي API، ولا تكلفة.** المساعد الذكي صار **محليًا 100%** يعمل من قاعدة معرفة داخل المشروع، **يعرض مصادره دائمًا**، ويقول «لا أعرف» بدل أن يخمّن.

> 📌 اقرأ أيضًا: [`SECURITY.md`](SECURITY.md) (سياسة الأمان) و [`DEVELOPMENT_PLAN.md`](DEVELOPMENT_PLAN.md) (المراحل) و [`ARCHITECTURE_AUDIT.md`](ARCHITECTURE_AUDIT.md) (الفحص).

## 1) نظرة عامة

**الهدف:** منصة تعليمية قبطية موجّهة للشباب: تتعلّم فيها الألحان وتتدرب عليها، وتلعب وتتنافس، وتفهم طقوسك، كل ذلك بمعلومة موثّقة.

**المبادئ الحاكمة (ملتزم بها في كل سطر):**
1. **لا تخمين** — أي معلومة غير مؤكدة تُعلَّم `📝 NEEDS_ADMIN_INPUT` وتظهر بهذه الشارة في الواجهة.
2. **حقوق النشر** — لا نسخ كتب أو عظات كاملة. مقتطفات قصيرة + بيانات وصفية + روابط.
3. **لا افتراض إتاحة المصادر** — كل مصدر له `searchable` و `access_note`. لا نتجاوز تسجيل دخول أو صلاحيات أو مجموعات خاصة أو robots.
4. **لا أسرار في الكود** — لا مفتاح واحد في أي ملف (يوجد اختبار آلي يتحقق).
5. **لا حماية وهمية** — لا نقدّم بوابة JavaScript كأنها أمان.

**الجديد في v3 (مقابل النسخة السابقة):**
- ❌ إزالة مفتاح Gemini وإزالة استدعاء Google كليًا → ✅ مساعد محلي مجاني بلا أي مفتاح.
- ✅ **تركيز قوي على الألحان** (جديد: 25 لحنًا + 3 نغمات + رتبة القداس + خطوات الحفظ).
- ✅ **4 ألعاب جديدة موجّهة للشباب**: الذاكرة، فكّ الكلمة، وصّل اللحن، أكمل الآية.
- ✅ أمان أقوى: تنظيف المفاتيح القديمة، سبع طبقات تحقق إدخال، `safeUrl`، ملف سياسة أمان.
- ✅ قسم طقس اليوم/التقويم القبطي + السنكسار بمدخلات موثّقة فقط.
- ✅ 18 شعارًا و8 مستويات + عدّاد تسبحة + توصيات ذكية.

**أمثلة جاهزة للمشاركة:**
- `#/quiz/lobby?mode=daily` → تحدي اليوم (نفس الأسئلة للجميع)

- `#/hymns/agios` → لحن أجيوس
- `#/bot?q=ايه معنى كيرياليسون` → سؤال جاهز للمساعد

**اختصارات لوحة المفاتيح:** `/` = بحث · `Alt+H` = الرئيسية · `Alt+G` = الألعاب

## 7) المساعد المحلي — بدون أي مفتاح 🤖

**كيف يعمل:**
1. يبني فهرسًا من كل وحدات المشروع (ألحان، مصطلحات، حروف، محتوى، أشهر، أعياد، مصادر، آيات).
2. يفهم السؤال بتطبيع عربي متسامح + كشف نية (تحية/مساعدة/عن المشروع/طريقة حفظ).
3. يسترجع أفضل العناصر، ويكتب الإجابة منها فقط، ثم **يعرض المصادر دائمًا**.
4. لو لا توجد نتيجة → يعتذر بالرسالة القياسية `APP.BOT.UNKNOWN` (بلا اختلاق).

**لماذا هذا أفضل من مفتاح API؟**
| | المساعد المحلي v3 | مفتاح Gemini سابقًا |
|---|---|---|
| التكلفة | مجانية تمامًا | حصة يومية محدودة |
| المفتاح | لا يوجد | مطلوب من المستخدم |
| الخصوصية | كل شيء في جهازك | يُرسل السؤال لطرف ثالث |
| الإنترنت | يعمل بدونه | مطلوب |
| الاختلاق | مستحيل (لا يخترع) | ممكن (روابط مُختلقة) |

## 8) تشغيل المشروع

**أ) محليًا:** افتح `index.html` مباشرة، أو:
```bash
python3 -m http.server 8080     # ثم افتح http://localhost:8080
```
> لا build، ولا تثبيت مكتبات، ولا dependencies خارجية (صفر مكتبات خارجية — أسرع تحميل وأقل تعرّض).

**ب) GitHub Pages (الطريقة المطلوبة):**
1. ارفع الملفات كلها إلى المستودع (**يجب رفع المجلدات `css/` و `js/` معها** — الموقع لا يعمل بملف index وحده).
2. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `root` → Save.
3. بعد دقيقة سيكون الموقع على `https://<user>.github.io/<repo>/`.
4. `.nojekyll` و `404.html` مضمّنان جاهزين.
> ⚠️ على GitHub Pages **لن تعمل الجداول** (لا توجد قاعدة بيانات) — والموقع مصمّم ليعمل كاملًا بدونها: النتائج تُحفظ محليًا بشارة «محلي»، والاقتراحات تُحفظ كمسودات.

**ج) نشر مع قاعدة بيانات (D1):** من **Publish tab** → نشر بضغطة واحدة → تُنشأ الجداول الستة تلقائيًا.

## 9) الأسرار والمتغيرات البيئية

**لا يوجد أي secret في الكود.** للتحقق: ابحث في المشروع عن `AIza` أو `token` أو `api_key` — لن تجد شيئًا (ويوجد اختبار آلي في `tests.html` يتحقق من ذلك ويفشل لو ظهر).

- **لا مفتاح AI مطلوب أصلًا** — المساعد محلي.
- **تنظيف تلقائي:** عند أول تشغيل يمسح `Store.purgeLegacySecrets()` أي مفتاح Gemini قديم محفوظ في متصفح المستخدم من النسخ السابقة.
- **لا مفاتيح بوت ولا credentials قاعدة بيانات ولا admin IDs** في الواجهة (وهذا مقصود).

## 10) قاعدة البيانات والتوسّع

- الجداول مُعرَّفة في `.tables/schema.json` (6 جداول) وتُنشأ عند النشر.
- **قبل النشر:** كل `fetch` يفشل بأمان → الموقع يعمل كاملًا بالبيانات المحلية والمسودات.
- **بعد النشر:** تُدمج بيانات الجداول مع البيانات المحلية تلقائيًا بدون تكرار.

⚠️ **توسيع المخطط:** إضافة جدول أو عمود تتم بـ **نشر عادي** (يضيف الناقص ويحفظ الصفوف). **لا تستخدم `rebuild_db`** لأنه يحذف كل بيانات الإنتاج.

📌 **تنبيه:** بيانات المعاينة (المُدارة من المحرر) **منفصلة** عن قاعدة الموقع المنشور (D1). لإظهار صفوف على الموقع المنشور، تُنسخ إلى قاعدة الإنتاج باستعلام `INSERT`.

### ⚠️ تنبيه أمني صريح (مطبوع داخل الصفحة أيضًا)
اللوحة **ليست محمية**. أي بوابة JavaScript يمكن قراءتها من كود الصفحة. لذلك:
- **لا تضع فيها أي كلمة سر أو مفتاح أو بيانات شخصية.**
- التعديلات «المنشورة للجميع» تحتاج خدمة خلفية بمصادقة حقيقية.
- اللوحة للتنظيم والمسودات المحلية — وهذا مكتوب في الواجهة نفسها (تبويب «الأمان»).

```js
['نص السؤال', 'خيار1', 'خيار2', 'خيار3', 'خيار4', 0, 'hymns', 'easy', 'الشرح', 'internal_hymns', ['وسم']],
// الترتيب: السؤال، 4 خيارات، فهرس الصحيح، التصنيف، الصعوبة، الشرح، معرف المصدر، الوسوم
```

لحن في `js/data/hymns.js`:
```js
{ id: 'hymn_id', name: 'الاسم', coptic: 'Ⲡ…', translit: '…', occasion: ['liturgy'],
  tune: 'adam', level: 1, sequence: 3, incipit: 'مطلع قصير جدًا',
  meaning: 'المعنى', note: 'ملاحظة عملية', learn: ['خطوة…'],
  needs_review: true, source_id: 'internal_hymns' }
```

> ⚠️ أي معلومة غير مؤكدة: اكتب `NEEDS_ADMIN_INPUT` في الشرح/الملاحظة — **لا تُخفِ الشك**.

## 13) حل المشاكل (Troubleshooting)

| المشكلة | الحل |
|---|---|
| الموقع لا يفتح على GitHub Pages | تأكد أنك رفعت مجلدات `css/` و `js/` — الموقع لا يعمل بـ index وحده |
| المساعد لا يجيب على سؤال | طبيعي: يجيب فقط من قاعدة المعرفة. جرّب صيغة أخرى، أو استخدم البحث الذكي |
| نتائجي غير موجودة في المتصدرين | تُحفظ محليًا بشارة «محلي» عند تعذّر الاتصال؛ تظهر للجميع بعد النشر بقاعدة بيانات |
| لا أرى تغييرات بعد تعديل | Cache reload (`Ctrl+Shift+R`) — وعلى الموبايل أغلق التبويب وافتحه |
| طلبت دقة في البحث | البحث يطبّع الهمزات والتاء المربوطة والتشكيل — اكتب الكلمة الأساسية بلا تشكيل |
| ظهرت شارة NEEDS_ADMIN_INPUT | مقصود: العنصر يحتاج مراجعة/إدخالًا ولم نخمّنه |
| أريد حذف بياناتي | صفحة «ملفي» → «تصفير كل بياناتي»، أو «امسح أي مفاتيح قديمة» |

## 14) ما لم يُنفّذ بعد (بصراحة)

| العنصر | السبب |
|---|---|
| بوت Telegram حقيقي + Handlers/Webhook | يحتاج سيرفر و bot token — مستحيل في موقع ثابت |
| مسابقات لحظية بين اللاعبين (WebSocket) | يحتاج خادم؛ الموجود: غرفة بكود + نفس الأسئلة + نتائج مجمّعة |
| تحقق سيرفر-سايد كامل ضد الغش | يحتاج خادم؛ المطبّق: لا تُرسل الإجابة قبل إجابة اللاعب + الحساب داخل المحرك |
| مصادقة وأدوار آمنة للـAdmin | يحتاج خادم — أي بوابة JS قابلة للقراءة |
| محتوى السنكسار (365 مدخلًا) | فقط مدخلات موثّقة؛ الباقي `📝 NEEDS_ADMIN_INPUT` (يحتاج مصدرًا مرخّصًا) |
| نصوص البابا شنوده الكاملة | حقوق نشر — بطاقة وفهارس وروابط فقط |
| رفع ملفات/صوتيات (ألحان صوتية) | يحتاج تخزينًا ومعالجة خلفية |
| دمج Chatbase | يحتاج حسابًا ومفتاحًا — وغير مستخدم (المساعد محلي) |
| الروابط الرسمية لمدارس الشمامسة + الواتساب | `📝 NEEDS_ADMIN_INPUT` — تُضاف من `#/admin` |
| تدقيق نطق الألحان مع مرتل | `📝 NEEDS_ADMIN_INPUT` — كل الألحان المعلَّمة تحتاج مراجعة مرتل |

## 15) الخطوات التالية المقترحة

1. **تدقيق الألحان مع مرتل قبطي متقن** (أهم بند — كل الألحان المعلَّمة `needs_review`).
2. **مراجعة كنسية** لبنك الأسئلة، خاصة أسئلة العقيدة والتاريخ.
3. **إدخال مدخلات السنكسار** من مصدر مرخّص (أو تركها فارغة بلا نص مُخترع).
4. **توثيق الروابط المفقودة** (مدرسة الشمامسة، استفانوس، الواتساب) من `#/admin`.
5. **توسيع مستوى «خبير»** بأسئلة متقدمة موثّقة.
6. **اختياري (يحتاج backend):** مصادقة إدارة، تحقق سيرفر-سايد، مسابقات لحظية، صوتيات.
7. **قبل العرض النهائي:** افتح `tests.html` وتأكد أن **كل** الاختبارات ناجحة.
